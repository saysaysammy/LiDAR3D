# Model Checkpoints

This directory stores pretrained model weights required by SFA3D.

## Download

Download the pretrained checkpoint from the original [SFA3D repository](https://github.com/maudzung/SFA3D) and place it at:

`Model/SFA3D/checkpoints/fpn_resnet_18/fpn_resnet_18_epoch_300.pth`

Make sure the filename and directory structure match the paths expected by the application.

Note: Please review the original checkpoint's distribution terms before redistributing the weights.
